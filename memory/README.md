# Project memory

Only reviewed, non-sensitive project context belongs in version control.

- authored/: human-authored or explicitly reviewed goals, facts, and constraints.
- handoffs/: reviewed continuity notes with completed work, evidence, open
  questions, and the next action.

Include a date and source when useful. Label assumptions and proposals; do not
convert plans into achievements. Avoid private conversations, credentials,
personal histories, and raw third-party information.

Runtime records, generated indexes, model transcripts, and private scratch data
belong in ignored locations such as memory/runtime/ or .local/. These directories
are conventions for future work, not an implemented memory service.

Memory is context, not authorization. Keep sensitive records local and inspect
any proposed tracked note before publication.
