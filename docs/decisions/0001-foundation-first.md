# 0001: Establish the foundation before adopting a runtime stack

Date: 2026-10-27
Status: accepted for this initial setup by the founder's explicit request.

## Context

The project starts with two local Gemini research reports and an empty GitHub
repository. The founder has a very limited budget and authorized a normal initial
commit and push of reviewed, non-sensitive foundation files.

## Decision

Create the requested minimal repository, project instructions, a draft planning
skill, and documentation. Preserve both original reports without moving or
modifying them; exclude them from Git. Publish a source index and proposed roadmap.

Use main and the existing origin at https://github.com/claudenunc/Family-OS.git.
Preserve any remote history and never force-push. Review an explicit staging list.

Do not install a framework, external skill, model gateway, cloud service, or
application dependency in this phase. Defer implementation language and runtime
selection until the first useful workflow is defined.

## Consequences

This provides a reviewable starting point with no new service or dependency cost.
It is not a runnable application. The draft skill needs real-use evaluation and
maintainer acceptance. A fresh clone contains the research index, not the private
local source documents. Product, budget, compatibility, and license claims in the
reports require current primary-source verification before adoption.
